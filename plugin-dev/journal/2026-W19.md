### Bug fix: kanban-server.py HTML rendering broken (JS syntax error)

**File:** `~/.claude/plugins/pensare/kanban-server.py`, line 359

**Bug:** The `do_GET` handler rendered the HTML template using:
```python
html = HTML.replace("{project}", self.project)
```
The `HTML` template string uses Python format-string escaping (`{{` → `{`, `}}` → `}`) for all CSS and JS braces, with `{project}` as the only real substitution. `.replace()` does not process these escapes — it leaves every `{{` as a literal `{{` in the browser, causing a JavaScript `Uncaught SyntaxError: Unexpected token '{'` before any JS could execute. The `fetch("/api/board")` call never ran, leaving the board stuck on "Loading… Connecting…".

**Fix:**
```python
html = HTML.format(project=self.project)
```
`.format()` correctly collapses `{{` → `{` and `}}` → `}` while substituting `{project}`.

**Symptom:** Board showed correct project title (HTML loaded fine) but no network call to `/api/board` was made — visible in browser DevTools Network tab with only the initial page load and an injected extension script.

### Feature: drag-and-drop column moves + PATCH API

**Motivation:** Status updates previously required Claude commands, costing tokens. Now handled entirely in the browser.

**Changes to `kanban-server.py`:**
- `update_item(item_path, updates)` — updates frontmatter fields in place and optionally appends a note under `## Notes`
- `regenerate_index(kanban_dir)` — rebuilds `INDEX.md` from all item files; called after every write
- `do_PATCH` on `KanbanHandler` — handles `PATCH /api/items/{id}` with JSON body `{status, priority, title, note}`
- HTML template: cards are `draggable="true"`; columns have `ondragover`/`ondragleave`/`ondrop` handlers; `dragStart/dragEnd/dragOver/dragLeave/drop/patch()` JS functions added; CSS adds `.card.dragging` and `.column.drag-over` visual states

**How it works:** Dragging a card to a new column calls `patch(id, {status: slug})` → `PATCH /api/items/{id}` → `update_item()` + `regenerate_index()` → board refreshes. Zero tokens.
