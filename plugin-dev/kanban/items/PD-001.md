## Description

The `do_GET` handler used `.replace("{project}", ...)` to render the HTML template. The template uses Python format-string escaping (`{{` / `}}`) for all CSS and JS braces, which `.replace()` does not process — leaving literal `{{` in the browser output and causing `Uncaught SyntaxError: Unexpected token '{'` before any JS executed.

Fix: changed line 359 of `kanban-server.py` to `.format(project=self.project)`.
