## Description

Cards are now draggable between columns. Dropping triggers PATCH /api/items/{id} which updates the item frontmatter and regenerates INDEX.md server-side. No Claude tokens required for status changes.

New server functions: update_item(), regenerate_index(), do_PATCH().
